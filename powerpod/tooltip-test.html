Implementation Details

  • Tooltip Component: Uses Shoelace's sl-tooltip component
  • Icon: Uses Shoelace's sl-icon with "question-circle" name
  • Conditional Rendering: Tooltip only appears when question has tooltip content
  • HTML Rendering: Uses slot="content" with unsafeHTML() for rich formatting
  • CKEditor Support: Properly handles HTML content from CKEditor including styles and formatting
  • Styling: Custom CSS for hover effects and positioning
  • Accessibility: Includes aria-label for screen readers
